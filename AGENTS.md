# Agent instructions

- Read `README.md` for calculation boundaries and local setup.
- Keep pension formulas in `src/lib.rs`; the WASM wrapper reuses this core.
- Keep shared UI text and behavior consistent between `frontend/index.html` (HTTP) and `web/index.html` (WASM). Preserve their different calculation transports.
- Edit the static page in `web/`, and the HTTP page and icons in `frontend/`; `dist/` is generated by `sh scripts/build-web.sh`.
- Check Rust changes with `cargo test`. For WASM or static frontend changes, run `sh scripts/build-web.sh` and `node tests/wasm.cjs`.
- `tests/wasm.cjs` runs `tests/site.cjs`: validate each inline script separately, shared UI copy, privacy disclosures, SEO metadata, and copied build assets. Run `node tests/site.cjs` after building for site-only checks.
- Keep canonical and Open Graph URLs aligned with `web/robots.txt` and `web/sitemap.xml` at `https://pension-calculator.rothcold.me/`; the build copies both crawler files to `dist/`.
- Both pages reference Vercel Analytics and Speed Insights. Keep privacy text accurate about these scripts and the WASM versus HTTP calculation transports.
- Update this file when meaningful project changes affect these instructions.
