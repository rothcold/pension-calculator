假设、限制与计算说明

    适用范围与示例假设

    本工具采用上海普通企业职工养老保险的简化模型，仅估算基础养老金与个人账户养老金。修改基数或费率不等于支持其他地区或参保类型。

    不适用的情形

    不涵盖城乡居民养老保险、机关事业单位特殊规则、视同缴费年限、过渡性养老金、特殊工种、提前退休、跨地区复杂核定及其他专项待遇；灵活就业的缴费成本和领取资格也须另行核对。本版不自动判定渐进式延迟退休时间或延缴资格。

    初始值不是核定值

    默认年龄 40 岁、账户余额 0 元、已缴 0 个月、月入账 1,000 元均为示例；退休年龄 63 岁、历史缴费指数 1、增长率与记账利率 0% 均为假设。计发基数 12,577 元仅为演示值，不是已核实的退休计发基数。请按权益记录及适用政策修改，未来规则也可能变化。

    计算方式与隐私说明

    WASM 版将表单输入交给浏览器内的 Rust / WebAssembly 计算，不调用 HTTP 计算接口。计算代码不主动持久化输入；托管平台及第三方脚本的数据处理另受其配置和政策影响。

    两套前端均引用 Vercel Analytics（访问统计）和 Speed Insights（性能监测）脚本。在托管环境启用时，相关脚本可能向 Vercel 发送访问与性能数据。计算代码未主动将表单字段作为统计事件发送，但这不构成对第三方脚本采集或传输行为的保证。请勿填写姓名、身份证号等身份信息。
